# NodeJS Starter Boilerplate Code Generator
Save time and generate nodejs boiler plate code and folder structure within a single command

**NOTE:** Your project folder for nodejs must be empty

## Steps: 
1. Install extension
2. Open an empty project folder
3. Open command palette (CTRL + Shift + P)
4. Run `nodejs boilerplate code`
